# S1 · Цифровой полигон эвакуации НПЗ в остановочный ремонт

Прототип для конкурса КМГ «Лучшие инновационные идеи и практики в области ОЗТОС». Агентная симуляция эвакуации 1 600 человек, облака H₂S или пожара и ИИ-штаба: правки ПЛА проверяются до аварии на одних и тех же людях и погоде.

**Все данные синтетические:** площадка, люди, подрядчики, наряды, метео и учение вымышлены. Снимок площадки сгенерирован. Модель служит для сравнения вариантов и тренировки, а не для инженерного расчёта зон поражения.

## Как открыть

Готовый файл — `evakuaciya-npz.html`: откройте его в браузере. Он работает без сервера и без интернета; шрифты, движок, данные и снимок встроены.

## Что внутри

- **Обзор проекта** — главный вывод: 210 → 24 → 7 неучтённых на 30-й минуте.
- **Подготовка:**
  - «Площадка» — генплан, ограждения с датами, перенос пунктов сбора, проверка связности, недели ремонта, подложка-снимок;
  - «Население» — e-PTW и СКУД с обезличиванием;
  - «Сценарии аварий»;
  - «ПЛА и меры» — правила и вклад каждой из 7 правок.
- **Расчёт:**
  - «Симуляция» — карта с людьми и облаком;
  - «Пакетные прогоны» — сценарии × погоды × стратегии, считаются в Web Workers;
  - «ИИ-штаб» — журнал решений, закрытый список команд.
- **Учения:** «Тренажёр штаба», «Сверка с учением» — подбор параметров и критерии приёмки.
- **Результаты:** «Отчёты» (PDF и DOCX, русский и казахский), «Инструктаж подрядчиков».
- **Администрирование:** роли, интеграции, журнал аудита, проверка персональных данных, резервные копии.

## Сборка

```bash
node build.js
```

Собирает `src/` в `evakuaciya-npz.html` и `public/index.html`. Нужен только Node.js 18+, зависимостей нет.

- `src/engine.js` — движок симуляции: люди, шлейф, пожар, учёт на ПС;
- `src/data.js` — готовые прогоны демо;
- `src/server.js` — «бэкенд» в браузере: хранилище, API по маршрутам ТЗ, пул вычислителей, агент штаба;
- `src/ui.js`, `src/s-*.js` — оболочка, карта и экраны.

Для разработки: `node serve.js` → http://localhost:8790/evakuaciya-npz.html

## Хостинг

`render.yaml` описывает статический сайт для Render: Dashboard → New → Blueprint → этот репозиторий. Render выполнит `node build.js` и опубликует папку `public`.
